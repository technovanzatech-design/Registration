# Animation Nexus

Build a Premium Computer Animation Symposium Website

Role

Act as a senior Frontend Developer and UI/UX Designer.

Create a production-ready, modern, premium symposium website for a Final Year Computer Science student.

This website is for an Intra College Symposium organized by the Department of Computer Animation.

The website should not look like a normal college website. It should feel like a premium technology conference similar to Adobe MAX, Apple Event, Google I/O, SIGGRAPH, or NVIDIA GTC.

Use React, TypeScript, Tailwind CSS, shadcn/ui, Framer Motion, and Lucide Icons.

The code must be clean, responsive, reusable, component-based, and easy to connect with a backend later.
